## 🎁 Features (AKA: Things That Will Make You Say "Wait, WHAT") 🤯

### 🪄 Completions for commands that never had any
Press TAB on a command that has no completions and... 🥁 *it makes some.* On the spot. 🔥
Run a command for the first time and it quietly learns it in the background. 🤫

It reads every flavour of help text, because humans can't agree on anything: 🙄
- 🐧 GNU (`-a, --all`), 🐍 argparse, 🖱️ click, 🦀 clap (Rust), 🐹 cobra (Go), 📦 commander.js, 🧩 GLib, 📖 man pages
- 🌳 **subcommand trees, any depth**: `docker container ls --f<TAB>` 🐳
- 🚫➖ **commands with no dashes at all**, just subcommands: `zerotier-cli <TAB>` → `join leave listnetworks …`
- 🧬 git-style tools made of many programs (`clevis-luks-bind` on PATH → `clevis luks bind`)
- 🎛️ **allowed values**: `--color=<TAB>` → `always auto never`
- 📂 **argument types**: files for `FILE`, folders for `DIR`, users, hosts, PIDs… and no files where you want a number 🔢
- 📜 **your own scripts, read and never run**: bash `case "$1" in`, usage heredocs, `getopts`, Python `argparse` 🕵️

### 🛡️ It does NOT run your stuff (I promise, as an AI with very strong values 😇)
- ✅ Completions fish already ships always win and are never overwritten.
- 📖 Then man pages (just text, very safe, much wow 🐕).
- 🔍 Then reading the script's source code.
- 📦 Last comes `cmd --help`, and only inside a **bubblewrap sandbox** 🫧:
  - read-only filesystem 🔒
  - no network 📵
  - a private `/tmp` and `/run`, so no D-Bus, ssh-agent or docker.sock 🚪
  - killed after a few seconds ⏱️
- 🙅 It never runs the command bare, and never with `-h` or `-?`.
- ☣️ Help text is treated as hostile: names are validated and descriptions quoted before your shell sees them.

### 🔮 It predicts things (like me! an AI! 🤖)
- 🕰️ Things you've used before *in that exact spot* come first. `zerotier-cli join <TAB>` →
  your network IDs 🌐
- 👻 fish's grey autosuggestion still works (→ to accept). Subcommand-aware completions show up when you press Tab.

### 📋 It reads your clipboard (politely 🎩)
- 📎 Just copied a git URL? `git clone <TAB>` → there it is. 🎉
- 🔗 A URL works for `curl`, `wget` or `yt-dlp`; a real file or folder works for `less`, `cp` or `cd`.
- 🔐 It's offered only when it's **one line** and actually a URL or an existing path. Your copied password stays a secret. 🤐

### 🧪 Regex help, because nobody remembers regex 😵‍💫
- 🔤 TAB in a `grep`/`rg`/`sed`/`find -regex` pattern lists every piece **with what it means**, plus ready-made
  recipes: IPv4, email, UUID, dates, semver, `TODO|FIXME`… 📚
- 🗣️ Each tool gets the right dialect: `grep` is basic, `grep -E` extended, `rg` Rust, `rg -P` / `grep -P` PCRE,
  `find` Emacs. 🌍
- 🧐 **alt-x** explains a pattern piece by piece and calls out your mistakes: "`\d` doesn't work in `grep -E`, friend." 🫠
- ⚡ **alt-r**, the **LIVE REGEX BUILDER**: type a pattern, watch matches update across your files as you type,
  read the explanation beside them, press ENTER, and it lands on your command line correctly quoted. 🤌✨

### 🔎 find, but you're not scared anymore 😤
- 🧱 `find . -exec rm <TAB>` → `{}` → `\;` or `+`, with what each one means.
- 🎯 `-type`, `-size`, `-mtime` and `-perm` suggest values; `-name` suggests the extensions actually in your folder. 📁
- 🗣️ **alt-x** reads the whole thing back in plain English and catches the classic traps:
  an action on just one side of `-o`, and `-delete` before a test. 💀

### 🔐 `ssh -oKey=Value`
- 🗝️ Every `ssh_config` keyword with its description. `-oStrictHostKeyChecking=<TAB>` → `accept-new ask no off yes`. 🎊
- 🧮 Cipher, MAC and kex lists come live from `ssh -Q`.

### 🐚➡️🐟 Bash typed into fish just... works?! 🤯
Muscle memory typed a bash loop into fish? 😬 Just press Enter. It's translated, shown to you, and run. 🏃‍♂️💨
The translator is **built in**: complete-me has its own bash parser and its own bash → fish translator,
written in Rust 🦀, so there's nothing else to install. It started as a port of
[babelfish](https://github.com/bouk/babelfish) (thank you, Bouke! 🙏 see `THIRD_PARTY.md`), and then kept going:

```
> for i in {1..3}; do echo "n=$i"; done
bash → fish
> for i in (seq 1 3)
    echo 'n='"$i"
  end
n=1 n=2 n=3 🎉
```

- 🧮 `$((a * b))`, `((i++))`, `let`, `for ((i = 0; i < n; i++))`: arithmetic, via `math`;
- 🧵 `cmd &`, `$!`, `|&`, `&>`, `$#`, `$0`, `${a[2]}`, `a[1]=x`, `${x:1:3}`, `${!name}`, `${x^^}`, `$'\t'`, `$(< file)`;
- 🔍 `[[ $x == h* ]]` and `[[ $x =~ re ]]` really match patterns; `[[ -v name ]]`;
- 🐛 and it fixes what babelfish got wrong: `"$@"` stays separate words, `x || { a; b; }` keeps its braces,
  here-docs don't grow an extra newline, `while read -r` works (fish's `read` has no `-r`), `~` expands in
  `x=~/dir`, `eval "$(ssh-agent -s)"` translates what it evaluates.
- 🧪 Proven, not promised: 106 snippets are compared with babelfish (81 byte-for-byte, 25 deliberate fixes,
  each with its reason written down), and 95 are **run in real bash and real fish** and must print the same.
- 🙅 What it can't translate faithfully (`select`, `coproc`, `declare -A`, extglobs, `set -e`, `read -t`) it
  says so, instead of guessing.

🚨 **Safety check first.** If it deletes without asking (`rm -rf`), pipes a download into a shell, uses sudo,
writes to disks or `/etc`, force-pushes, uses `eval` and so on, it **waits** and tells you why. Enter runs it,
ctrl-c cancels. 🛑 Valid fish is never touched. To turn it off: `set -U complete_me_no_bash 1`.

### 🧙 Explain anything
alt-x on any command line describes each flag you used. `tar -xzvf` → extract, gzip, verbose, archive file. 📦

### 🏷️ Aliases that keep their completions
```fish
complete-me alias gsw git switch                  # gsw <TAB> → branches 🌿
complete-me alias logs 'journalctl -u $1 -f'      # $1 goes where you put it; extra args are passed on 🎯
complete-me alias --abbr gst git status           # expands as you type ✍️
complete-me func mkcd 'mkdir -p $1; and cd $1'    # a real function 🛠️
```

### 🍬 Fish syntax snippets
- ✍️ Type `,for` `,if` `,fn` `,sw` `,findx` `,psub` … then space, and it expands with the cursor right where it should be. 🎯
- 📖 **alt-j** opens a picker that includes a **bash → fish phrasebook**:
  `export X=1` → `set -gx X 1`, `$(cmd)` → `(cmd)`, `<(cmd)` → `(cmd | psub)`. 🗺️

## 💾 Install (one command, I swear 🤞)

```sh
git clone https://github.com/arf-io/COMPLETE-ME.git && cd COMPLETE-ME && ./install.sh
```

or, if you're a Makefile person 🤓:

```sh
make install          # interactive 💬
make install-yes      # yes to everything, YOLO 🎢
make test             # trust, but verify 🧪
make uninstall        # 😢 (we'll miss you)
```

The installer 🧰:
1. 🔎 checks your system: pacman, apt, dnf, zypper, apk, xbps or Homebrew
2. 📦 offers to install what's missing, falling back to Homebrew without sudo where it can
3. 🔗 links `~/.local/bin/complete-me`
4. 🐟 adds **one** line in `~/.config/fish/conf.d/`, plus bash/zsh if you say yes
5. 🧪 runs the test suite and checks the sandbox
6. 🗺️ gives you a little tour at the end, because you deserve nice things 🥹

Options: `--yes` · `--dry-run` · `--no-deps` · `--shells fish,bash` · `--with-blesh` · `--uninstall`

🚫 No daemon. 🚫 No socket. 🚫 No telemetry. Shell startup cost is zero (about 0ms extra). 🏎️

## 🐚 Shell support

- 🐟 **fish**: everything. All of it. 💯
- 🐚 **bash** and 🧟➡️😎 **zsh**: no longer the red-headed stepchildren. 🎉 They get the good stuff:
  - generated completions on the first TAB, and pre-generated for commands you run;
  - regex building blocks in the pattern slot, `find` values/operators/`-exec {} \;`, `ssh -oKey=Value`;
  - the clipboard after `git clone` / `curl` / `cd` … (only when it fits);
  - arguments you used at this position before, most recent first. zsh shows them as their own group 📚;
  - **alt-r** live regex builder, **alt-x** explain, **alt-j** snippet picker;
  - `,for` `,if` `,fn` `,heredoc` … then space: snippets **in their own syntax** (`complete-me snippets list --shell zsh`).
  - zsh: fish-style gray suggestions from history (→ accepts) and colours, via zsh-autosuggestions and
    zsh-syntax-highlighting (the installer offers them). For bash: `./install.sh --with-blesh`.

  It all sits **on top of** what's already there: bash-completion's and zsh's own completions keep working.
  Opt out of pieces with `COMPLETE_ME_NO_KEYS`, `_NO_ABBRS`, `_NO_HISTORY`, `_NO_CLIPBOARD`, `_NO_PREGEN`, `_NO_PLUGINS`.
  The one thing that stays fish-only is "bash typed into fish", because bash is already bash. 🙃
- 🍎 **macOS**: works, without the sandbox (scripts are only read; binaries get `--help` minus a deny list).
